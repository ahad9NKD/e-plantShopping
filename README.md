# e-plantShopping

**e-plantShopping** is a React shopping-cart application for Paradise Nursery, an online plant store. Users can browse plants by category, add plants to a cart, adjust quantities, remove items, and view the total cost of their order.

## Features

- Landing page with information about Paradise Nursery
- Plant catalog organized into categories
- Add-to-cart functionality
- Cart quantity controls and item removal
- Cart item count and order-total calculation
- Navigation between the home page, plant catalog, and shopping cart

## Technologies

- React
- Redux Toolkit and React Redux
- Vite
- CSS

## Run the project locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite in your browser.

## Build for production

```bash
npm run build
```
